# Narration audio

Drop the exported MP3s here, named by step ID from `../SCRIPT.md`:

```text
step_01_welcome.mp3
step_02_sidebar_setup.mp3
step_03_robot_profile.mp3
step_04_quality_bands.mp3
step_05_ingest_gate.mp3
step_06_upload_and_stream.mp3
step_07_review_queue.mp3
step_08_audit_history.mp3
step_09_dataset_quality.mp3
step_10_labels_coverage.mp3
step_11_closing.mp3
alert_error.mp3        (optional)
```

The guided tour plays `<id>.mp3` for each step and shows the same text as an
on-screen caption. A missing file is not an error — the step just shows its
caption silently, so the tour always works even before the audio is recorded.
